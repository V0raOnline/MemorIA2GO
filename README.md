## What is MemorIA2GO?

MemorIA2GO is a focused tool that converts your ChatGPT export into a clean, project-organized vault of Markdown files, ready to be used as live context in Claude Desktop via MCP (Model Context Protocol).

Unlike generic migration tools that only transfer saved memories, MemorIA2GO brings your **full conversation history** — organized, deduplicated, and immediately accessible.

---

## How it works

MemorIA2GO runs a 3-step pipeline:

**Step 1 — Import & Convert**
Parses your ChatGPT export (`.zip`, `.json`, or `.html`) and generates one `.md` file per conversation with clean YAML frontmatter: title, date, tags, and project mapping.

**Step 2 — Organize by Project**
Reorganizes the vault into project-based subfolders using the `Project_name` field in each note's frontmatter. Supports year/month subfolders within each project.

**Step 3 — Deduplicate**
Removes delta copies and hash variants generated by ChatGPT's export format. Keeps only the canonical version of each conversation, significantly reducing vault size.

## Quick Start

### Requirements

- Python 3.9+
- Claude Desktop
- Node.js (for MCP server)

### Install dependencies

```bash
pip install rich pyyaml beautifulsoup4 lxml
```

### Run

```bash
python MemorIA2GO.py
```

The wizard will ask for:
- Path to your ChatGPT export file or folder
- Destination vault folder
- Gizmo map (project ID → name mapping, optional)
- Project vault name (default: `PRJ_VAULT`)
- Year/month subfolder organization
- Index generation

If a `memoria_config.yaml` is present, it loads automatically and offers to use preconfigured values.

---

## Connect to Claude Desktop via MCP

Once your vault is ready, add it to Claude Desktop's MCP config:

**Location:** `%APPDATA%\Claude\claude_desktop_config.json` (Windows) or `~/Library/Application Support/Claude/claude_desktop_config.json` (Mac)

**Install MCP filesystem server:**
```bash
npm install -g @modelcontextprotocol/server-filesystem
```

**Config:**
```json
{
  "mcpServers": {
    "filesystem": {
      "command": "mcp-server-filesystem",
      "args": [
        "C:\\path\\to\\your\\vault\\PRJ_VAULT"
      ]
    }
  }
}
```

Restart Claude Desktop. Claude can now search and reference your full conversation history on demand.

## Configuration

Edit `memoria_config.yaml` to set persistent paths and options:

```yaml
paths:
  base_vault: 'path/to/output'
  exports_dir: 'path/to/chatgpt/exports'
  gizmo_map: 'path/to/gizmo_map.json'

options:
  prj_vault_name: 'PRJ_VAULT'
  by_year: true
  by_month: true
  make_index: true
  dry_run: false
  keep_hashes: false
```

### gizmo_map.json

Maps ChatGPT project/GPT IDs to human-readable names. Format:

```json
{
  "g-abc123...": "my-project-name",
  "g-xyz456...": "another-project"
}
```

**How to build your gizmo_map.json:**

1. Open ChatGPT in your browser and navigate to each Project or custom GPT
2. Copy the ID from the URL — it appears after `/g/` and looks like `g-p-6bd...4a2`:
   ```
   https://chatgpt.com/g/g-p-6bd............4a2-my-project-name
   ```
3. Copy the project name from the ChatGPT interface
4. Add both to your `gizmo_map.json`:
   ```json
   {
     "g-p-6bd............4a2": "my-project-name"
   }
   ```

Repeat for each project. Conversations without a mapped ID will be grouped under `none/`.

## File Structure

```
MemorIA2GO/
├── MemorIA2GO.py           # Main orchestrator
├── split_chatgpt_export.py # Step 1: Export → Markdown
├── project_organizer.py    # Step 2: Organize by project
├── vault_dedup.py          # Step 3: Deduplicate
├── config_loader.py        # YAML config loader
├── memoria_config.yaml     # Configuration
├── gizmo_map.json          # Project ID → name mapping
└── requirements.txt        # Python dependencies
```
